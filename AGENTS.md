# Agent Instructions

Project guidance for this repository lives in [`CLAUDE.md`](CLAUDE.md). Read it first.

## Conventions

- **Git and GitHub text is English only.** Commit messages, branch names, PR titles and descriptions, review comments and replies, and issue text are never in Turkish, even when the work touches Turkish user- or operator-facing strings. Quote a Turkish string in backticks when the change is about it, and explain it in English. Turkish text inside the product itself (UI, error messages shown to operators) is unaffected.
- **PR titles** follow [Conventional Commits](https://www.conventionalcommits.org/en/v1.0.0/); the `check-pr-title` workflow enforces it.
